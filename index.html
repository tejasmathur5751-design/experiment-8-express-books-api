Express.js Architecture

  • Routing: app.get(), app.post(), app.put(), app.delete()

  • Route Params: req.params.id for identifying book IDs
  • HTTP Status Codes: 200 OK, 201 Created, 404 Not Found

RESTful API Endpoints Specification

Standard HTTP verbs and endpoints implemented in the Express.js server router

Method Endpoint Route Description Request Body Response Status
GET /books Retrieve all books in the catalog None 200 OK
GET /books/:id Fetch a specific book record by its numeric ID None 200 OK / 404
POST /books Add a new book entry to the library database { title, author, category, year } 201 Created
PUT /books/:id Update an existing book's details by ID { title, author, category, year } 200 OK / 404
DELETE /books/:id Remove a book permanently from catalog None 200 OK / 404
